# 🎉 Eventra CRM

A modern event booking CRM system to manage events, customers, and bookings in one place.

---

## ✨ Features

* 📅 Browse and explore events
* 📝 Book events through a form
* 🔐 Admin login system
* 📊 Admin dashboard to manage bookings
* 🎨 Premium pastel SaaS-style UI

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Node.js, Express
* **Storage:** Local storage / basic backend setup

---

## 🚀 How to Run Locally

1. Clone the repository

```bash
git clone <your-repo-link>
```

2. Open project folder

```bash
cd eventra-crm
```

3. Install dependencies

```bash
npm install
```

4. Start backend server

```bash
node server.js
```

5. Open frontend
   Just open `event-index.html` in your browser
